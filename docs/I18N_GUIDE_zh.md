# i18n 开发指南：英文版翻译与排版

> 本文档面向负责「英文版界面」的协作者。核心：**翻译在 i18n.c 一处加词条，排版在 nav_lang.c 每页函数里调**。中文版完全不受影响。

## 1. 整体机制（30 秒理解）

```
数字键 6 切英文（或产品设置页选语言）
页面进入/重建时：
  1. 生成代码写中文默认值（根部文件，别碰）
  2. 动态文本（状态条/按钮）→ tr() 查表替换英文（已包装好，472 处）
  3. nav_lang 树遍历：静态标签文本命中表→英文；taiwanpearl 字体→aktivgrotesk
  4. 当前页有注册排版函数 → 调用（你可以在这里调坐标/字号）
切回中文：tr() 原样返回 + 树遍历早退 → 页面完全是中文
```

**关键**：中文模式所有英文机制零执行，逻辑零影响。

## 2. 翻译词条怎么加

文件：`custom/i18n.c` 的 `s_table[]`

```c
static const i18n_t s_table[] = {
    { "空气炸",           "Air Fry" },          // 纯文本
    { "| 空气炸 | %d℃ | %02d分钟",
      "| Air Fry | %d℃ | %02d min" },          // 格式串（占位符必须一一对应！）
    ...
};
```

规则：
- 查表是**整串精确匹配**（`tr("中文")` → 找完全一样的 zh）
- 格式串条目：`%d`/`%s` 占位符顺序和数量必须与英文版完全一致
- 换行符 `\n` 直接写进字符串，英文版可自己排版断行
- 翻译词条来源参考 `SKU123456中英繁对照表2026-5-9.xlsx`（在 sku3_最新资料 目录）

## 3. 排版调整（你的主战场）：nav_lang.c

### 3.1 注册一个页面排版函数

```c
/* nav_lang.c */
void air_menu_lang_tune(void)   /* 函数名随意，对应 PAGE_AIR_MENU */
{
    air_menu_t *m = air_menu_get(&ui_manager);
    if (!m) return;                       /* 页面未建好兜底，必须有 */
    lv_obj_set_pos(m->temp, 500, 240);    /* 调坐标 */
    lv_obj_set_style_text_font(m->temp, &c_aktivgroteskmedium_24, 0);  /* 调字号 */
    lv_label_set_text(m->hour_label, "Hrs");  /* 个别可覆盖文本 */
}

static const struct { page_id_t page; lang_tune_fn fn; } s_tune_tab[] = {
    { PAGE_AIR_MENU, air_menu_lang_tune },  /* 注册 */
    /* 没问题的页面不用注册，零成本 */
};
```

### 3.2 工作流（改排版的标准流程）

```
1. 模拟器按 6 切英文
2. 进到目标页 → 看到文字溢出/错位/字体不对
3. 打开 nav_lang.c → 找到该页 tune 函数（没有就新建+注册一行）
4. 写 lv_obj_set_pos / set_style_text_font / set_text
5. 重新编译运行 → 重进页看效果
```

### 3.3 动态标签排版（烹饪中/状态条等每秒刷新的）

**放心**：`lv_label_set_text()` 每秒重写的是文本，**不会动**你设好的坐标/字号（对象样式独立）。
所以动态标签的排版同样在 tune 函数里设一次即可，不会被打回。

## 4. 字体

| 用途 | 字体 | 字号 |
|------|------|------|
| 中文默认 | taiwanpearl_regular | 23/24/30/36/48/60/72/128 |
| 英文 | aktivgroteskmedium | 24/30/36/48/60/72/128（树遍历自动切换） |

- 英文文本会自动映射同字号 aktivgrotesk（nav_lang.c 里 else-if 链）
- 字号 23 无英文对应档，保留 taiwanpearl 显示（含拉丁字形，可正常显示）
- 如果某处英文显示需要整体调小，可在该页 tune 函数里 `set_style_text_font` 指定更小字号

## 5. 常见问题

| 现象 | 原因 | 解法 |
|------|------|------|
| 某词条仍是中文 | 词条不在翻译表 | i18n.c 加一行 `{ "中文", "English" }` |
| 英文文字溢出 | 英文比中文长 | 该页 tune 函数缩小字号/移动位置 |
| 切英文后当前页没变 | 需要重进页面 | 切英文后退出再进入目标页（或按 Tab 重进菜单） |
| 格式串翻译错乱 | 占位符数量/顺序不一致 | 检查 i18n.c 该条目 `%d`/`%s` 与中文版一致 |
| 某些按钮文字仍是中文 | 文本写在根部生成文件 | 树遍历会自动覆盖；若没覆盖，确认页面重建触发（走 page_push/pop） |

## 6. 别做的事

- ❌ 不要手改 `ui_builder/*.c` 根部文件（sync 脚本会覆盖）
- ❌ 不要动业务逻辑（状态机/定时器/g_send/页面栈）
- ❌ 不要给 printf 调试日志加翻译
- ❌ 不要在中文路径加英文判断（`is_english()` 只应出现在 i18n/nav_lang 层）
